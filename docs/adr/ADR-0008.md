# ADR-0008 — Execution surfaces & models

**Status:** Accepted (role definitions superseded by ADR-0011) · 2026-06-21

## Context
Multiple AI surfaces are involved in building and running this project. Roles and model tiers must be explicit to control cost and maintain the determinism invariant.

## Decision (original; role definitions updated by ADR-0011)
- **Brain** = Opus 4.8 (Claude.ai project + Claude Code plan mode) — now re-scoped to optional outside advisor.
- **Hands** = Claude Code in VS Code, default **Sonnet 4.6**, Opus for the number path + reviews.
- **Cowork** = orchestrator/planner/evaluator window (Sonnet 4.6).
- **Runtime** = deterministic (no LLM in the number/verdict path; LLM only in `narrative/`).

## Consequences
See ADR-0011 for the updated role map (orchestration v2). The determinism invariant is unchanged.
