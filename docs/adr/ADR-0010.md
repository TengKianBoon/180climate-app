# ADR-0010 — Report generation & lead delivery

**Status:** Accepted · 2026-06-21 · **Deciders:** John (owner), Claude (architect)

## Context
Each user's carbon pre-feasibility output should be delivered as a professional document. 180Climate needs the lead data and a copy of the report for follow-up. A single delivery system minimises complexity.

## Decision
Each report is generated in **both PDF (user download) and DOCX (internal email)**. Filenames = creation timestamp `YYMMDDHHMM` (same base for both files; use the earlier of the two creation times).

**On download**, the app:
1. Emails **info@180climate.net** with the DOCX attached + full lead-form details, subject `"{concession name} — {filename}"`.
2. Appends the lead to the Google Sheet (ADR-0004).

The report **ends with the "Engage 180Climate" CTA** (full FS, field validation, methodology advisory, hi-res/LiDAR, EUDR compliance, project development, market access).

Secrets (email + Sheets credentials) live in host environment config — **never in the repo**.

## Consequences
+ Single inbox (`info@180climate.net`) for lead capture and download notification.
+ Google Sheet backup.
+ PDF for the user; DOCX for internal use (more editable for follow-up).
**Gate P** verifies this end-to-end before go-live.
