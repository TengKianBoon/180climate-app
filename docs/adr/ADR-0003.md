# ADR-0003 — Funnel gating

**Status:** Accepted · 2026-06-21 · **Deciders:** John (owner), Claude (architect)

## Context
The app is a lead-generation + data-collection funnel. There is a tension between giving users enough value to trust the tool and capturing lead data for 180Climate's business.

## Decision
**Light capture up front** (name + email to see the headline verdict + map); **detailed report + financial-model carrot gated behind the full lead form**.

Full lead form fields: name, email, mobile, company, concession name, permit type, project type, area, geometry summary.

## Consequences
+ Lower friction at the top of the funnel (more users try it).
+ High-intent users who want the full report self-select into giving full contact details.
− Users who only fill name + email see less detail — must ensure the headline verdict is still compelling enough.
