# ADR-0007 — Data sources & licensing

**Status:** Accepted · 2026-06-21 · **Deciders:** John (owner), Claude (architect)

## Context
The app uses satellite and geospatial data for forest-loss queries, biomass estimates, and peat mapping. Many high-quality datasets are available free-of-charge but have non-commercial-only licences. Using them in a commercial product without a licence agreement is a legal risk.

## Decision
Free-tier sources **behind a swappable interface** (all data access goes through a single module; swapping the provider requires no engine-code change). **GEE (Google Earth Engine) is non-commercial only** → flagged in the README and this ADR; ship MVP on free APIs / self-hosted COGs where possible; reserve paid hi-res for flagged plots only.

**Data source list (free tier, v1):**
- Forest loss: GFW/Hansen annual loss tiles
- EUDR baseline: JRC Global Forest Cover 2020
- Near-real-time alerts: RADD
- Biomass proxy: ESA CCI Biomass / JAXA
- Land cover: ESA WorldCover
- Peat maps: CIFOR/Wetlands International
- DEM: SRTM

## Consequences
+ Reproducible free-tier setup documented in README.
+ Swappable interface means paid sources can be plugged in per-client without engine changes.
⚠️ **GEE non-commercial caveat** — prominently stated in README; production deployments must use a commercial GEE licence or substitute sources.
