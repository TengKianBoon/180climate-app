# ADR-0006 — Peat methodology

**Status:** Accepted · 2026-06-21 · **Deciders:** John (owner), Claude (architect)

## Context
The Verra standalone tropical-peatland method is still in development. VM0027 is interim and requires advisor confirmation. Branding the app to a specific peat method before the methodology is finalised would date the product.

## Decision
**Agnostic + advisor-confirm** — peat presented as a transparent avoided-drainage/subsidence range, **never branded to VM0027 as a settled method**; the narrative states "advisor-confirm; standalone peat method pending." The advisor confirms the method for each commercial deal.

## Consequences
+ Won't date itself to a transitional method.
+ Stays defensible when the standalone peat method is finalised.
− Users see "advisor-confirm" language; acceptable given the genuine uncertainty in the peat methodology space.
