# ADR-0002 — Hosting / platform

**Status:** Accepted · 2026-06-21 · **Deciders:** John (owner), Claude (architect)

## Context
The existing 180Climate website is built on Wix, which cannot host a custom Python + FastAPI application or serve a React frontend with full geospatial capabilities.

## Decision
Build a **standalone app on a subdomain** (`app.180climate.net`), **linked from the Wix navigation** + optional iframe embed. John adds the DNS/subdomain record in Wix DNS settings.

## Consequences
+ Full control over the stack (Python, FastAPI, React, MapLibre/Leaflet).
+ Clean separation between the marketing site (Wix) and the tool (standalone).
− Requires DNS setup (one-time, ~5 minutes).
− Two deployments to manage (Wix + the app host).
