# ADR-0009 — Uncertainty & confidence communication

**Status:** Accepted · 2026-06-21 · **Deciders:** John (owner), Claude (architect)

## Context
Carbon pre-feasibility estimates carry significant uncertainty. Presenting a single point estimate as "the answer" would be misleading and professionally indefensible. IPCC Tier language provides a standard framework for communicating data quality.

## Decision
The engine **always outputs a range (low/high) + an uncertainty band**, **never a single value and never a "% accuracy."** The narrative uses **IPCC Tier language**:
- Free/open satellite data → "Tier 1 — indicative screening estimate"
- Higher-res / LiDAR → "toward Tier 2 — improved pre-feasibility"
- Field + accredited methodology + independent verification → "Tier 3 — registry-grade"

The narrative must state: **the baseline/counterfactual — not satellite resolution — is the dominant uncertainty.** Field validation + accredited methodology + third-party verification are required before any creditable/financial claim.

Full rationale: `docs/carbon-confidence-report.pdf`.

## Consequences
+ Defensible against methodology scrutiny.
+ Sets correct expectations (positions the full FS as the precision upgrade).
**Gate M** verifies all golden cases assert the range + band + IPCC tier. A lint/test fails the build if a single bare carbon number or any "%accuracy/%confidence" string appears in engine or narrative output.
