# ADR-0005 — Build order / public scope

**Status:** Accepted · 2026-06-21 · **Deciders:** John (owner), Claude (architect)

## Context
The app has two engines (Carbon Pre-FS + EUDR Readiness) sharing a geospatial core. Building both in parallel risks scope creep and delays the first shippable milestone.

## Decision
**Carbon vertical first → ship → EUDR fast-follow** reusing the shared core. Carbon-only is a valid public v1 if the window tightens.

## Consequences
+ Carbon is a shippable milestone on its own (generates leads, demonstrates the architecture).
+ EUDR fast-follows with ~60% reuse from the shared core.
− The EUDR deadline (operators 30 Dec 2026, SMEs 30 Jun 2027) creates time pressure; the fast-follow must stay fast.
